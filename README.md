### What I'm building

**WEDGE Method** is an AI operating system for independent consultants. Six proprietary systems that replace seventeen tools — client research, proposals, reports, follow-ups, invoicing, and insights — all automated.

I believe solo consultants should compete with firms 10x their size. AI makes that possible. I'm building the tools to prove it.

### Stack

TypeScript · Next.js · Node.js · Vercel · Stripe · Ollama · VS Code Extension API

### Philosophy

- Build in public. Ship daily. Iterate based on data.
- Zero manual labor. If a human has to do it twice, automate it.
- Local-first AI. Your data stays on your machine.
- Open source the tools. Sell the system.
